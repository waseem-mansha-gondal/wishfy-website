# Wishfy Website

> wishfy.ai — AI-native search visibility consultancy

## Tech Stack
- **Framework:** Astro 5
- **Styling:** Tailwind CSS v4
- **CMS:** Keystatic (git-based)
- **Hosting:** Vercel
- **DNS/CDN:** Cloudflare
- **Analytics:** Plausible
- **Monitoring:** Sentry
- **Languages:** EN, NL, DE, FR

## Getting Started

```bash
pnpm install
pnpm dev
```

## Company Setup
Brand assets, agent definitions, and company config live in the separate [wishfy-company](https://github.com/wishfyai/wishfy-company) repo.
